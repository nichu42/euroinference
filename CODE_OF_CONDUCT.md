# Code of Conduct

EuroInference is a small open-source project built through respectful collaboration. Everyone participating in issues, pull requests, reviews, discussions, documentation, and other project spaces is expected to help keep them welcoming and constructive.

## Expected behavior

- Be respectful, patient, and technically constructive.
- Assume good faith while remaining open to correction.
- Explain disagreements with evidence and focus on the work, not the person.
- Welcome contributors with different backgrounds, experience levels, identities, and communication styles.
- Respect project boundaries around privacy, security, licensing, and third-party services.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, sexualized conduct, hate speech, deliberate disruption, and publishing someone else's private information without permission are not acceptable. Attempts to expose security vulnerabilities publicly before coordinated disclosure are also inappropriate.

## Enforcement

Project maintainers may edit, hide, or close comments, issues, and pull requests that violate this code, and may restrict participation when necessary to protect the community. Maintainers will try to explain moderation decisions when doing so does not create additional harm or compromise a security report.

Report conduct concerns privately to `nichu42@42bit.email`. Security vulnerabilities must be reported according to [`SECURITY.md`](SECURITY.md), not through a public issue.

This code applies wherever someone is representing or participating in the EuroInference project. Retaliation against a good-faith report is not acceptable.
