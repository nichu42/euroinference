2. Controller and scope

The data controller for EuroInference's own processing is the provider named in the Impressum above. No separate data protection officer has been appointed for this project. Privacy requests can be sent to the controller by email or post.

This notice covers the hosted dashboard, the static files it serves, and voluntary contact through the published email address or GitHub repository. Deploybase, GitHub, provider websites, and other external services act under their own privacy policies for processing they control.

3. No dashboard accounts or tracking

The browser dashboard does not ask for an account and does not intentionally collect, profile, sell, or transmit search terms, filters, workload assumptions, model selections, or usage analytics. It contains no advertising SDK, analytics service, telemetry, crash reporter, or tracking cookie.

The dashboard reads the generated data.js file shipped with the site. Filtering, sorting, currency selection, comparison details, and workload estimates are calculated in the browser.

EuroInference's own processing is limited to operating and securing the informational website and responding to voluntary inquiries. Where personal data is processed by the project, the usual legal basis is Article 6(1)(f) GDPR (legitimate interests in providing, securing, and maintaining the service) or the legal basis applicable to the specific inquiry. No automated decision-making or profiling takes place.

4. Local browser storage

The page stores the selected light/dark theme in browser localStorage under the euroinference-theme key. Search terms, filters, token assumptions, and comparison state are kept in page memory and are not sent to the project.

You can remove the theme preference by clearing site data for the dashboard or deleting that local storage key. Browser cache behavior is controlled by your browser and hosting infrastructure.

The theme preference remains in your browser until you clear it or the browser removes it. EuroInference does not receive or retain a copy.

5. Network requests from the browser

The public dashboard at euroinference.sites.deploybase.eu is hosted on deploybase, a static hosting platform operated by TwanIT, a sole proprietorship in the Netherlands. When you open the hosted dashboard, your browser necessarily makes ordinary requests to deploybase and its delivery infrastructure for HTML, CSS, JavaScript, images, fonts, and generated data.

Deploybase's privacy policy states that the platform processes IP addresses in server logs and API request logs to provide the service, prevent abuse, and maintain security. It describes EU infrastructure hosted by Scaleway in Paris and CDN delivery through Bunny.net, and lists a 30-day retention period for server access logs containing IP addresses. These practices are controlled by deploybase/TwanIT, not by EuroInference. Please consult deploybase's policy for the current details, your data-protection rights, and its contact address.

EuroInference does not use deploybase account features, forms, analytics, or tracking services. The project does not control the host's operational logs or retention.

The dashboard does not contact provider APIs or other model services during page load. It reads the static data cache shipped with the site. Links that you choose to follow to GitHub, provider websites, documentation, or other external services are governed by those services' privacy policies.

For hosting requests, Deploybase and its infrastructure/CDN providers are the relevant recipients of connection metadata. Deploybase's policy describes EU infrastructure and global CDN delivery; any processing or transfer decisions made by those providers are governed by their policies and safeguards.

6. GitHub repository and issue tracker

The source code, documentation, issue tracker, and pull requests are hosted on GitHub. When you visit or use these GitHub features, GitHub may process account details, public contributions, attachments, timestamps, IP addresses, browser information, and other service metadata under the GitHub Privacy Statement.

Issues, pull requests, comments, and attachments may be public and can be copied or indexed by others. Do not post passwords, API keys, personal data, private provider responses, or security vulnerabilities in public GitHub content. Use the contact method in SECURITY.md for security reports.

EuroInference maintainers can read and respond to content submitted through GitHub, but do not control GitHub's hosting, logging, retention, international transfers, or privacy practices. GitHub's own retention and transfer rules apply to GitHub-hosted content.
